# Quantum Harmonic Oscillator: solved numerically, checked exactly

A one-day physics demo that solves the Schrödinger equation for the harmonic oscillator numerically and checks every number against the exact textbook answer.

**Result:** All 12 energies match the exact values to within 8.3 × 10⁻⁴, and the error falls by a factor of 4.0 each time the grid spacing halves, as second-order finite differences should.

**Status:** Complete.

- Only the 1D, time-independent harmonic potential is validated.
